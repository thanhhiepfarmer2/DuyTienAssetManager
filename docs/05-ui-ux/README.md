# UI/UX

Mỗi màn hình ghi actor, dữ liệu, thao tác, quyền và trạng thái loading/empty/error/success; hỗ trợ thiết bị thuộc phạm vi.
UI dùng tiếng Việt. Web dùng Razor Pages và app Android/iOS dùng .NET MAUI;
thiết bị/OS mục tiêu vẫn chưa được chốt. Danh sách phạm vi hiện tại ở
[SCREEN-LIST](SCREEN-LIST.md).
Không tự thêm i18n, QR hoặc offline nếu Requirement chưa có.
