# Kiểm thử

Dùng mẫu TEST-REPORT hoặc ghi trực tiếp trong Task nếu ngắn. Liên kết từng acceptance criterion với test hoặc thao tác nghiệm thu.
[ACCEPTANCE-PLAN](ACCEPTANCE-PLAN.md) là kế hoạch case mức sản phẩm; chưa có test
ứng dụng nào được chạy vì repo chưa có mã.
Tập trung hành vi thành công, sai đầu vào, quyền, trùng dữ liệu và đồng thời theo phạm vi; test phù hợp với rủi ro.
Test chưa chạy phải ghi NOT_RUN; chức năng chưa có mã không được báo pass.
Nếu cần người dùng UAT, hướng dẫn bước thử và kết quả mong đợi; lưu kết quả thật trước DONE khi UAT bắt buộc.
